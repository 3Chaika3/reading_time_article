# Расширение для Chrome "Таймер чтения статей"

Простое расширение для Хрома (на Manifest V3), которое считает, сколько минут осталось читать статью, и вешает аккуратную черную плашку в угол экрана. Во время скроллинга время меняется динамически

## 🛠️ Как это работает
1. **Ищет текст:** Скрипт пытается найти на странице теги `<article>`, `<main>` или класс `.post-content`. Если находит — забирает оттуда текст.
2. **Считает время:** Берет общее число слов и делит на среднюю скорость чтения (180 слов в минуту). Считает картинки внутри статьи и накидывает по 10 секунд на каждую для точности.
3. **Следит за экраном:** Через `getBoundingClientRect()` функция постоянно чекает координаты статьи при скролле. По формуле высчитывается процент прокрутки и обновляется цифра на плашке.

## 📂 Содержание
* `manifest.json` — настройки и доступы плагина для браузера.
* `style.css` — стили для плашки (сделала фиксированную позицию в углу, темную тему и немного теней).
* `content.js` — весь код, который считает слова, картинки и скролл.
